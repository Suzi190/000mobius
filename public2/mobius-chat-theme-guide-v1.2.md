# 莫比乌斯机｜自制聊天主题教程

适用模板：`mobius-chat-beauty-template-v1.2.css`  
说明日期：2026 年 10 月 4 日（导入入口：聊天「我」页 →「装扮」）

这份教程教你把配色、图片气泡、底栏贴纸和聊天背景做成一个可以导入的小手机聊天主题。可以自己写，也可以把空白模板、素材和要求一起交给 AI。

模板是空白格式，不带现成主题。请复制一份再制作，保留原文件方便以后使用。

## 1. 先认识这个主题能改什么

这是小手机提供的**受限 CSS 美化接口**。只有模板列出的部件和属性会生效，不是普通网页的全部 CSS 都能使用。

| 可以制作 | 不在这份接口的支持范围 |
| --- | --- |
| 页面、卡片、文字、图标、边线的配色 | 字体、字号、头像、昵称 |
| 双方气泡颜色、圆角、边线、阴影 | 任意宽高、定位、布局、移动按钮 |
| 图片九宫格气泡、连续消息首条气泡 | 在线下场景描写上套聊天气泡或改描写格式 |
| 主题聊天背景 | 把主题背景铺到线下、约会或所有页面 |
| 四个底栏入口的图片贴纸 | 随意增加选择器、伪元素、脚本 |
| 顶栏、底栏和侧边栏的底色与模糊质感 | `@import`、`@font-face`、`@media` |

**不要改模板中的选择器名字。每段能用哪些属性，看它上方的注释。** 同一种属性在某个部件可用，并不代表在其他部件也可用。

气泡透明度继续跟随小手机里的透明度设置。字号请在软件里调整。图片气泡也跟随气泡透明度。

## 2. 准备与导入

1. 在聊天「我」页点「装扮」，点下方「导出空白格式」下载空白 v1.2 模板（也可以直接问小助手要），用能编辑纯文本的工具打开。
2. 另存为自己的主题名，例如 `樱粉奶油.css`，编码选择 **UTF-8**。
3. 在需要的部件花括号里填写样式。不需要的部件可以留空，也可以删除。
4. 文件总大小不得超过 **512 KB**，图片内嵌的数据也算在内；规则（花括号段）不超过 150 段。
5. 打开聊天「我」页 →「装扮」，左右滑到最后一张带加号的“导入”卡片，点它选择 `.css` 文件。（「我」页的「主题」只放自带的几套配色，导入的主题都在「装扮」里。）
6. 先看主题卡片预览，再点击应用，进入真实页面检查效果。

目前导入主题最多保存 **5 个**，可以在「装扮」里左右滑动切换、删除；达到上限时先删除不需要的主题。导入与应用是两个步骤，不要把导入成功当成已经切换。用着导入主题时，想换回自带配色，在「装扮」点「切回默认」，或者到「主题」里选一套。

最终交给别人的是一个 `.css` 文件。不要把 Word 文档改后缀，也不要把 Markdown 的代码围栏一起复制进去。检查文件名，避免实际保存成 `主题.css.txt`。

## 3. 第一步：先填齐六个基础色

制作时，如果出现“气泡变了，但搜索框、返回附近、卡片还是旧颜色”的情况，先检查基础配色。**先填齐六个基础色，再单独调整部件**，能让搜索、返回、输入栏等自动协调。

| 变量 | 用途 |
| --- | --- |
| `--mobius-page` | 页面底色 |
| `--mobius-surface` | 卡片、浮层底色 |
| `--mobius-text` | 正文、图标颜色 |
| `--mobius-muted` | 次要文字颜色 |
| `--mobius-accent` | 强调色 |
| `--mobius-border` | 分隔线、边线颜色 |

例如，在模板对应位置填入：

```css
.mobius-palette {
  --mobius-page: #fff7fa;
  --mobius-surface: #fffdfd;
  --mobius-text: #57434d;
  --mobius-muted: #927b86;
  --mobius-accent: #bb6c8d;
  --mobius-border: #efdce5;
}
```

上面只是教学配色，可以全部替换。页面底色和卡片底色可以接近，但正文需要清楚可读。

六个变量只能填写合法色值。其他部件可以引用它们：

```css
.mobius-search {
  background-color: var(--mobius-surface);
  color: var(--mobius-text);
  border: 1px solid var(--mobius-border);
  border-radius: 18px;
}
```

也可以使用后备色，如 `var(--mobius-accent, #bb6c8d)`。不要自创其他变量，也不要嵌套变量。基础色没填时软件会尝试从其他部件推导，但制作完整主题时建议明确填齐。

## 4. 第二步：先做好普通气泡

`you` 是对方，`me` 是自己。下面是无需图片就能制作的气泡：

```css
.mobius-bubble-you {
  background-color: #fffdfd;
  color: #57434d;
  border: 1px solid #efdce5;
  border-radius: 18px;
  box-shadow: 0 2px 6px rgba(100, 65, 80, 0.08);
}

.mobius-bubble-me {
  background-color: #f7dce7;
  color: #57434d;
  border: 1px solid #edc6d7;
  border-radius: 18px;
}
```

复制示例时，用它替换模板中对应的空白段，避免同一个选择器到处重复。需要透明底时使用 `background-color: transparent;`，不要依赖不支持的 `opacity`。

### 支持的数值范围

| 项目 | 限制 |
| --- | --- |
| 普通边框宽度 | `0`、`1px`、`2px`，也可分别设置四边 |
| 圆角 | `0–32px`、`0–50%` 或 `999px` |
| 背景模糊 | `0–12px` |
| 阴影长度 | 每个长度的绝对值不超过 `24px` |
| 图片气泡的 `border-image-width` | `0–80px` |
| 图片气泡的 `padding` | `0–80px` |

普通边框宽度和图片边框显示宽度是两种设置，不要混为一谈。超出支持范围或不支持的声明会被忽略，其他有效声明仍会保留。

## 5. 进阶：制作图片气泡

猫咪、兔子、叶子等装饰气泡应使用**九宫格图片边框**。九宫格把图片分成四角、四边和中间，让文字变长时四角尽量保留形状，边和中间负责伸展。

不要把整张气泡图片当作普通背景强行拉满，否则短句看着正常，长句就可能把角色拉扁、压住文字。

### 素材怎么准备

- 优先使用带透明背景的 PNG 或 WebP。
- 装饰和边角尽量放在外围，中间留出可伸展的文字区域。
- 先看清图片的真实像素尺寸，再确定切片位置。
- 装饰越向文字区域伸入，就越需要留足对应方向的内边距。

### 九宫格写法

下面的地址是占位地址，发布前必须替换成自己的真实图片地址或完整内嵌数据。示例数值只演示写法，不能直接套到任意图片上。

```css
.mobius-bubble-you {
  background-color: transparent;
  color: #57434d;
  border: 1px solid transparent;
  border-image-source: url("https://example.com/bubble-you.png");
  border-image-slice: 24 30 24 30 fill;
  border-image-width: 12px 15px 12px 15px;
  border-image-repeat: stretch;
  padding: 12px 18px 12px 18px;
}
```

| 属性 | 怎么理解 |
| --- | --- |
| `border-image-source` | 气泡图片 |
| `border-image-slice` | 在原图哪里切开；使用原图片像素，必须加 `fill` |
| `border-image-width` | 切出来的边在页面上显示多宽；使用显示像素，范围 `0–80px` |
| `border-image-repeat` | 只支持 `stretch` |
| `padding` | 文字与气泡外围之间的留白，范围 `0–80px` |

**slice 使用原图像素；width 和 padding 使用显示像素。** `slice` 的这些数字不写 `px`，`width` 和 `padding` 的非零像素值写 `px`。

例如，一张自己绘制的气泡图片，某一边原图切片厚度是 24 像素，希望显示为 12 像素时，可以把对应 `slice` 写成 `24`，对应 `width` 写成 `12px`。这两个数不必相同，要根据图片细节与实际显示效果调整。

`fill` 必须保留，否则中间区域可能缺失。内边距要根据装饰位置调整，不能直接把切片数字当作内边距。

CSS 中四个方向的数值顺序统一为 **上、右、下、左**。例如 `padding: 10px 24px 12px 18px;` 表示上 10、右 24、下 12、左 18 像素。

### 首条有装饰，后续气泡简洁

这四个部件负责双方气泡：

| 选择器 | 用途 |
| --- | --- |
| `.mobius-bubble-you` | 对方普通气泡，后面的连续消息使用它 |
| `.mobius-bubble-me` | 自己普通气泡，后面的连续消息使用它 |
| `.mobius-bubble-you-first` | 对方连续消息首条，可选 |
| `.mobius-bubble-me-first` | 自己连续消息首条，可选 |

可以给首条用带猫咪的图片，给普通气泡用较简单的叶子或纯色。建议普通气泡先做完整，再填写首条样式；首条图片需要的切片、显示宽度和留白要按该图片单独设置。

## 6. 图片怎样放进文件

支持 HTTPS 图片链接，或 PNG、JPEG、GIF、WebP、AVIF 的 base64 内嵌数据。不要使用电脑本地路径、相对路径、HTTP 链接或 SVG 数据。

| 方式 | 优点 | 要注意 |
| --- | --- | --- |
| HTTPS 外链 | CSS 文件较小 | 图片需要联网读取；链接失效、限制访问或需要登录都会影响显示 |
| base64 内嵌 | 分享 CSS 时图片一起带走 | 会增大文件，完整 CSS 仍须小于等于 512 KB |

内嵌格式类似下面这样，`完整数据` 必须替换成实际编码，省略号不能导入：

```css
.mobius-nav-chats {
  background-image: url("data:image/png;base64,完整数据");
}
```

base64 编码通常会让图片数据体积增加约三分之一。贴纸和气泡先裁掉多余透明边、缩到合适尺寸、压缩，再内嵌；不要把大幅背景原图和多个高分辨率贴纸全部塞进文件。

## 7. 背景与底栏贴纸

### 聊天背景

```css
.mobius-chat-background {
  background-image: url("https://example.com/chat-background.webp");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
```

图片地址同样需要替换。`cover` 会铺满并可能裁切；`contain` 会尽量完整显示；`auto` 保留图片自身尺寸。可用的位置是 `center/top/bottom/left/right`，重复方式是 `repeat/no-repeat`。

**用户自己选的聊天背景始终优先。** 导入后没看到主题图，先检查是否已设置个人聊天背景；清除自选图后再看主题图。主题背景不作用于线下和约会。

圆点、花纹等背景只能放在这个聊天背景部件里。不要试图把图片放到会话列表、朋友圈或“我”页面：这些页面的底色部件不支持 `background-image`。

### 四个底栏入口贴纸

| 选择器 | 入口 |
| --- | --- |
| `.mobius-nav-chats` | 聊天 |
| `.mobius-nav-contacts` | 联系人 |
| `.mobius-nav-moments` | 朋友圈 |
| `.mobius-nav-me` | 我 |

这些部件只支持 `background-image`。建议使用透明底图片，裁掉过大的透明留白，四张素材保持相近的视觉大小。

软件保留底栏文字、未读角标和点击区域。写 `background-image: none;` 可以恢复原来的 SVG 图标；不能用 CSS 任意移动入口或改变点击范围。

## 9. 常见问题与处理方法

| 问题 | 检查与处理 |
| --- | --- |
| 气泡已变色，其他地方还白着或带薄荷色 | 先填齐六色板；检查卡片、列表、朋友圈、“我”页是否仍写了不协调的固定色 |
| 给列表和朋友圈铺了大片浓粉底，效果与原主题不符 | 区分页面底色、行／帖底色和聊天背景；浅色或透明卡片通常更容易保持层次，不要把聊天背景误当全应用背景 |
| 返回箭头下面出现深色方片 | 不要添加自造的返回选择器、额外方片或布局；使用模板的顶栏底板（`.mobius-nav-button`、`.mobius-topbar`）及文字槽（`.mobius-topbar-text`）。按模板写了仍出现，截图问小助手 |
| 线下背景深，透明顶栏的黑字看不清 | 给聊天顶栏设置足够实的浅色底，或选择适合的深底浅字组合；普通聊天与线下都要看，不要只检查浅色预览 |
| 地点名下面还有一块色片 | `.mobius-place` 可设透明底、透明边线、无阴影（写法见下方）；它只管顶栏里那个地点小标，不负责整个地点选择弹窗 |
| 导入后出现“部分样式未采用”列表 | 每行是“部件：忽略 属性”，表示这个部件不开放该属性，或数值超出范围；只有这一条不生效，其余照常。对照该段注释删掉或改小即可 |
| 图片气泡中间没了 | 检查 `border-image-slice` 是否带 `fill` |
| 长消息把装饰拉坏，文字挤到猫咪上 | 检查切片位置、原图像素与显示像素的比例、四边顺序和 padding；普通气泡与首条气泡分别调 |
| 图片不显示 | 检查是否为支持的图片类型、HTTPS 地址是否可访问、base64 是否完整；本地路径不能随 CSS 分享 |
| 主题背景不显示 | 检查用户自选背景，它的优先级高于主题背景 |
| 字号、字体、宽高怎么写都不变 | 这些不属于该模板支持范围，字号和透明度应使用软件设置 |
| 卡片预览正常，真实页面还有问题 | 预览不能代替所有页面检查，尤其线下背景、连续气泡、长消息、侧边栏、朋友圈 |

地点小标透明写法，填入模板原有段落即可：

```css
.mobius-place {
  background-color: transparent;
  border-color: transparent;
  box-shadow: none;
}
```

## 10. 发布前实际试一遍

- 检查文件后缀、UTF-8 编码和 512 KB 大小限制。
- 检查六个基础色、正文可读性，以及是否混入不支持的选择器或属性。
- 分别发送双方短句、长句、多条连续消息，观察首条和后续气泡。
- 测试小／大字号及低／高气泡透明度，检查图片气泡是否压字。
- 打开普通聊天、线下模式、侧边栏、会话列表、联系人、朋友圈、“我”和角色主页。
- 检查顶栏、返回、发送键、底栏贴纸与未读角标。
- 分别测试已设置个人聊天背景和未设置个人背景的情况。
- 检查所有图片地址，分享文件中不要包含私人资料、令牌或私有访问链接。

如果只有某一项不生效，先查该段允许的属性及数值范围，不要立刻重写整个主题。界面里出现模板无法控制的问题，也可能需要软件端修复。

## 11. 不会写 CSS？把这段交给 AI

把**空白 v1.2 模板和自己准备的图片素材**一起上传，再复制下面的说明，把方括号内容换成自己的要求：

> 请根据附件 `mobius-chat-beauty-template-v1.2.css`，制作一个莫比乌斯机／小手机可导入的聊天主题 CSS。风格是［配色与风格］，素材使用［附件素材说明］。请输出 UTF-8 的 .css 文件，最大 512 KB，不自动应用或修改软件。
>
> 严格使用模板现有选择器和各段列出的属性。先填齐 `.mobius-palette` 六个基础色，让搜索、返回、输入栏、卡片等配色协调。不要添加自定义选择器、其他变量、字体字号、任意尺寸、定位、布局、头像昵称、@import、@font-face 或 @media。
>
> ［若需要图片气泡］使用 border-image 九宫格，slice 按原图像素且必须加 fill，width 和 padding 使用显示像素，均在 0–80px 内，repeat 只用 stretch。检查原图像素与显示像素的比例及四边顺序；CSS 四值是上右下左。普通与首条气泡分别按素材调整，验证短句、长句与连续消息。
>
> ［若需要底栏贴纸］只在四个 mobius-nav 对应槽位设置 background-image，保留文字、未读角标与点击范围。
>
> ［若需要背景］只放在 `.mobius-chat-background`，保留用户自选聊天背景优先，不影响线下或约会。图片使用可访问的 HTTPS 地址或受支持类型的完整 base64，优先压缩并内嵌小素材。
>
> 检查白底／旧主题色残留、返回附近方片、深色线下场景中的顶栏文字可读性和地点小标。不要自造返回按钮选择器。先给可导入的试用文件，说明完成了哪些检查，并列出仍需在真实小手机里验证的内容。

制作顺序建议：**六色板 → 普通气泡 → 图片气泡 → 底栏贴纸／背景 → 其他部件 → 实际导入检查**。先完成一份简单可用的主题，再逐步加装饰。
